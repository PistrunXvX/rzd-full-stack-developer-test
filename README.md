# rzd-full-stack-developer-test

## Как запустить
### Зависимости
- NodeJS => 24

Установить пакеты<br>
`` npm install ``

Запустить dev сборку<br>
`` npm run dev``

Проект будет доступен по адресу
`` http://localhost:5173/ ``

## Что улучшил бы и что использовал
Проект собрал на Vue3 с использованием библиотеки Vuetify4. Интерфейс максимально простой, с использованием цветов и иконок material design от гугла.<br><br>
Реализовал тройную фильтрацию, где идет совмещение поиска по названию направления ``(trains.name)``, поиск по региону ``(trains.region)`` и поиск по месяцу отправления ``(trains.departures)``. При чем поиск по дате отправления фильтрует по всем датам отправления данного направления.<br><br>
Что можно было бы добавить и улучшить. С условием, что я придерживался дедлайна в 5 часов.<br><br>
- Декомпозировать обьект поезда ``train``. Т.к. сейчас все данные уходят в карточку направления напрямую из json файла, любое изменение 
и придется переписывать каждый вывод в компоненте, вместо исправления в исходном обьекте
- Добавил переключение светлой/темной темы. Куда без этого)
- Возможно рассмотрел бы опцию при переходе на страницу с открытым состоянием диалогового окна через query параметр запроса
